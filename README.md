# טיול יפן 2026 – Japan Trip Companion

אתר מלווה אינטראקטיבי לטיול הקבוצה ביפן (28 בספטמבר – 14 באוקטובר 2026).

## תכונות עיקריות

- **היום** – לוח יומי חכם עם מזג אוויר, תזכורות וצ'קליסט
- **לוח זמנים** – כל הימים עם סינון לפי עיר
- **מזג אוויר** – תחזית ל-14 יום לטוקיו, האקונה, אוסקה וקיוטו (Open-Meteo)
- **טיפים** – הכנות, תרבות, אפליקציות, כסף וחנויות
- **כלים** – מחשבון מטבע, מעקב מזוודות, הזמנות, מלונות וטיסות
- **אופליין** – נתונים נשמרים במכשיר (localStorage)
- **מפות** – Leaflet + OpenStreetMap בכל יום רלוונטי

## איך להריץ מקומית

1. פתחו את התיקייה בשרת סטטי פשוט:
   ```bash
   npx serve .
   # או
   python3 -m http.server 8080
   ```
2. גלשו אל `http://localhost:8080` (או הפורט שמוצג).

**חשוב**: בגלל fetch ל-JSON ול-API של מזג האוויר, יש להריץ דרך שרת (לא לפתוח את הקובץ ישירות מ-`file://`).

## פרסום ב-GitHub Pages

1. Settings → Pages → Source: Deploy from branch `main` / root (or /docs).
2. האתר יהיה זמין ב-`https://mocd12.github.io/japan-trip-2026/`.

## עדכון תוכן

כל הנתונים נמצאים בקובץ אחד:

```

```

ערכו אותו והעלו מחדש. אין צורך לגעת ב-HTML/JS ברוב המקרים.
